# Club Assets

This folder contains club-specific images and assets used by the Hoops Planner application.
Replace these placeholders with your own club's branding.

## Files

| File | Description | Recommended Size |
|------|-------------|-----------------|
| `club-logo.png` | Club logo / emblem (icon-style) | ~200×200px |
| `club-logo-full.png` | Full club logo with text | ~800×400px |
| `club-photo.jpg` | Club or team photo for branding | ~1920×1080px |
| `signature.jpg` | Signature image (e.g., coach signature) | ~400×100px |

## Usage

These assets are currently not referenced in the application code. They are stored here
for future use in PDF exports, email notifications, and the web interface.

To use your own assets:
1. Replace the placeholder files with your own images
2. Keep the same filenames
3. Restart the application if needed

## Notes

- The `media/` directory is gitignored — these files are not tracked in version control
- Use PNG for logos with transparency, JPG for photos
- Keep file sizes reasonable (< 2MB each)
